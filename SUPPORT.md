# Getting Support

Thank you for using our open source software! Here is how to find help or report issues:

---

## Channels

### 1. Bug Reports
If you suspect a defect or regression in a specific repository:
- Search existing issues on that repository to see if it has already been reported.
- If not, open a Bug Report using the repository's issue form.

### 2. Feature Requests & Proposals
If you have an idea for an enhancement, API addition, or performance optimization:
- Open a Feature Request issue on that repository.
- Provide clear context and use cases.

### 3. General Discussions
If you have architecture questions or general inquiries:
- Use the **Discussions** tab on the repository (if enabled) or connect via GitHub profile links.

### 4. Security Vulnerabilities
- **Do not use public GitHub issues for security vulnerabilities.**
- Follow the private reporting instructions outlined in [SECURITY.md](SECURITY.md).
