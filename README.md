# .github

This repository contains account-wide default community health files, contributing guidelines, security policies, and issue/PR templates for repositories under the [@bhubbard](https://github.com/bhubbard) account.

Any repository owned by `@bhubbard` that does not define its own specific templates or health files will automatically inherit the defaults defined here:

- [Security Policy](SECURITY.md)
- [Contributing Guidelines](CONTRIBUTING.md)
- [Code of Conduct](CODE_OF_CONDUCT.md)
- [Support Guidelines](SUPPORT.md)
- [Pull Request Template](.github/PULL_REQUEST_TEMPLATE.md)
- [Issue Templates](.github/ISSUE_TEMPLATE/)
